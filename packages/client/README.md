# `@flarelobby/client`

FlareLobby の HTTP と WebSocket を扱うブラウザ向け TypeScript Client SDK です。
カスタムルーム、再接続、1 対 1 マッチング、ELO 取得を型付き API で利用できます。

```sh
pnpm add @flarelobby/client @flarelobby/core
```

初期化、Room、Ticket、再接続の手順は
[Client SDK ガイド](https://github.com/katsu996/FlareLobby/blob/main/docs/client.md)
を参照してください。
