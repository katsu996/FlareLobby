# `@flarelobby/testing`

FlareLobby の仮想時計、版固定乱数、決定論的マッチングシミュレーター、統計出力を
提供する ES Modules パッケージです。

```sh
pnpm add -D @flarelobby/testing @flarelobby/core
```

同じ入力と乱数種から同じ結果を再現でき、検索幅ポリシーごとの待機時間・レート差・
未成立チケットを比較できます。利用例は
[テストと検証](https://github.com/katsu996/FlareLobby/blob/main/docs/testing.md)
を参照してください。
