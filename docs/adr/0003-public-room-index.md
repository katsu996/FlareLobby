# ADR-0003: 公開ルーム一覧を D1 の投影にする

- 状態: 採用
- 日付: 2026-08-11
- 対象: 公開カスタムルーム一覧

## 背景

公開ルームを一覧表示するたびに全 Room Durable Object を探索すると、一覧 API が
Room 数に比例して遅くなり、全ルームを一つのオブジェクトへ集中させます。ただし
D1 への書込みは Room の状態変更と同時に確定できず、一時障害も起こり得ます。

## 決定

Room SQLite を正本とし、公開情報だけを D1 の検索用投影へ非同期で同期します。
投影には `revision` を付け、古い同期が新しい行を上書きしないようにします。
同期失敗は Room SQLite の pending operation と単一 Alarm へ保存して再試行します。
一覧に表示された空き枠や状態はヒントに過ぎず、参加 API は対象 Room Durable Object
を再確認して最終判定します。

## 代替案

- 一覧をメモリで保持する: 再生成と複数 Worker 間で不整合になるため不採用。
- 一覧を Room DO へ集中する: Room 数の増加に比例したホットスポットになるため不採用。
- D1 を Room の正本にする: WebSocket と Room 単位の強整合境界を損なうため不採用。

## 結果

検索・ページングは D1 で水平化でき、一覧投影が遅れても参加の正しさを失いません。
利用者は一覧が一時的に古い可能性を考慮する必要があります。
